# Rain Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Rain weather mode to Snowy: streak raindrops, level puddles on tops that run off, and a rising flood at the bottom whose surface is a damped 1D wave field that reacts to drops, runoff, the pointer and windows.

**Architecture:** A small water system beside the snow engine in SnowCore: `Weather` setting on `SnowSimulation`; a `FloodField` (level + wave heights) per simulation; a `puddle` depth per `SnowDrift`; raindrops/drips/splashes as particle arrays stepped in `SnowSimulation+Rain.swift`. Rendering adds a streak instance pipeline and a water fragment shader reusing the `SnowVertex` mesh layout. Snow code paths only change at the mode switch.

**Tech Stack:** Swift 6, SnowCore (pure Swift, XCTest), Metal (`Sources/Snowy/Shaders/Snow.metal`), AppKit menu.

**Spec:** `docs/superpowers/specs/2026-11-17-rain-mode-design.md`

- App bundle: `/Volumes/HDD/Xcode/snowy-mac/.harness/build-local-app.sh` → `Built /Volumes/HDD/Xcode/Snowy-fixed.app`.

## Global Constraints

- Snow mode must not change: the full existing suite (249 tests) stays green after every task.
- All water is drawn on the desktop plane, behind native windows; never over them.
- Flood level never exceeds `L_max` (Dock tray top above the screen bottom; 60 pt with no bottom Dock).
- Load in rain at Steady within the snow ranges measured on the M1 (Snowy ≈ 7–11 % CPU, GPU ≈ 12–36 %).
- Commit messages: no Claude attribution / Co-Authored-By lines (user preference).
- Constants from the spec (starting values): drop speed 450–750 pt/s, streak length 8–20 pt, width 1–1.5 pt, opacity 0.35–0.7; puddle `d_max` 3 pt (Dock 2 pt); drips ≤ 64, slide 120 pt/s, gravity 900 pt/s²; flood spacing 4 pt, `c ≈ 260 pt/s`, damping `k ≈ 1.6 /s`, amplitude clamp ±12 pt; flood reaches `L_max` in ≈ 5 min at Steady (≈ 10 min Light, ≈ 2.5 min Flurry) on 1920×1080 with no windows; melt: full cap empties in ≈ 40 s, **10:1 snow:water**; drain ≈ 20 s; puddle evaporation 2 %/s when not raining; `L_max` drop eases over ≈ 2 s; pointer splash threshold 450 pt/s.

## Review Focus

1. **Reduce Motion in rain** (no visible drops): the flood must still rise at the same pace via an ambient fallback, like snow's fallback. Test in Task 3.
2. **Rapid Snow↔Rain switching mid-transition** must continue from current state, no reset or jump. Test in Task 5.
3. **Clear Settled Snow during rain** must also empty puddles and the flood. Test in Task 5.
4. **Dock hidden / side / auto-hidden**: `L_max` = 60 pt and the flood still renders. Test in Task 1 (`capFallback`) and Task 7 wiring.
5. **Many windows / tiny tops**: puddle and drip budgets stay bounded (≤ 64 drips, puddles never negative). Test in Task 2.
