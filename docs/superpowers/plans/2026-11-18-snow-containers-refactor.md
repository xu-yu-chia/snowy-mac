# 雪的容器物理重構計畫（第 2 版，依 GPT 計畫審查修訂）

**起點：** commit `8399e07`。工作區未 commit 的半成品只當草稿，不沿用。

## 目標
視窗之間任何凹槽（可由多個視窗頂邊共同構成）都像容器一樣裝雪：
1. 一個盆地共用一個雪面；填到溢出口（短板頂）之後，上面再蓋一層有起伏的雪。
2. 雪面連續：接縫、牆的圓角都不能有平台直線、尖角、V 形缺口或兩層重疊。
3. 只從溢出口溢出：先落到短板頂端，接不住就在外緣變成鬆雪落下。溢出路徑不刪雪。
4. 底下有通往地面的空隙，或盆地寬度超過上限，就不是容器，維持一般積雪。

## 設計

### 1. 盆地與溢出口（場景改變時計算）
- 2 pt 一欄的地形：每欄取同平面（排除 elevated、Dock）最上面視窗的**含圓角**輪廓 y（新增 `SolidBody.contour(at:)`，與 `Surface.baseY` 同公式），並記錄擁有者；無視窗的欄是地面。
- 出口（drain）：螢幕左右邊緣、以及每個地面欄。
- 一維 priority-flood：`W[c] = min(往左到最近出口路徑上的最高點, 往右的最高點)`（以螢幕 y 表示，越小越高）。`W[c]` 比地形高的欄就是積水欄。
- 連續積水欄合成一個盆地；同一盆地的 `W` 天然是常數，就是盆地的雪位。盆地內高於雪位的高台會自然把它切成兩個盆地，各自有自己的溢出口。
- 溢出口：盆地左外與右外兩個邊界欄中，地形等於雪位的那一側（等高時取右側）。記下它的擁有者 `wallID`、靠盆地的邊 `wallX`、方向。
- 盆地寬度上限 `160 pt`；超過就不是容器。

### 2. 盆地樣點
- SnowDrift 樣點若「露出、未被壓住（`isFree`）、是該精確 x 的最上層輪廓、所在欄屬於盆地、且 `baseY > 雪位`」，就是該盆地的地板樣點，`depth = baseY − 雪位`。牆的圓角凹口因為地形含圓角，會自然被納入。

### 3. 共享雪面（每次 settle，取代盆地樣點上的 settle/creep/shedEnds）
- 盆地總雪量 `V = Σ hᵢ·wᵢ`（wᵢ 是樣點寬度）。任何入口（正常落雪、鬆雪落地、推雪、溢入）都只是加到 hᵢ，下一次 settle 統一重分配，所以不需要個別入帳。
- `V ≤ V_rim`（填到雪位的體積）：二分法解出共同水面 `L`，`hᵢ = max(0, baseYᵢ − L)`。
- `V > V_rim`：盆地填滿到雪位，多出的 `E` 形成雪帽。雪帽形狀用**螢幕座標**的 lobe 函式（跨 SnowDrift 一致，接縫不錯開），`capᵢ = f·capMaxᵢ`，`f = min(1, E / Σ capMaxᵢ·wᵢ)`。雪帽在溢出口那一側往牆頂雪面收斂（最後一段線性接到牆頂現有雪面高度），避免接縫高低差。
- 仍有剩餘就是溢出量，交給溢出口。
- 盆地樣點不參與 drift 內部的 settle 傳遞、creep、shedEnds（逐樣點排除）。

### 4. 溢出口
- 溢出量落到 `wallID` 視窗頂端靠盆地的邊，`depositMass` 方向朝盆地外；仍剩的成為該頂端的超載（其後依現有規則往可排出端移動）。
- 短板沒有 SnowDrift、或仍有剩餘：在 `wallX` 外側上方生成鬆雪（`SnowRelease`）；鬆雪預算滿時沿用現有的待釋放佇列，不刪除。

### 5. 場景改變（第一版範圍）
- 重算盆地前，盆地樣點中超出新容量的雪改成鬆雪釋放，不刪除。精確的新舊座標重映射（拖曳盆地）列為後續工作。

### 6. 移除與保留
- 移除：`joinedEnds`、`refreshJoinedEnds`、`slitSnowReachesTop`、`refreshBasins`、逐欄 64 pt 找牆、`ContainerFill` 的逐點溢出。
- 保留，並明列為刻意的雪量扣除：`roomBelow` 夾制（雪不高過壓在上面的視窗）、無可達端點的壓實、新視窗出現時的擦除。

### 7. 第一版明確不處理（維持一般積雪）
- 浮在凹槽上方、底緣不接觸的矮視窗；側面漏縫的連通判定；拖曳時的精確重映射；雨天容器。

## 測試（先寫、先看失敗）
1. 單一縫（小工具 54、Spotify 122、終端機 136）：雪位 122，溢向 Spotify。
2. 使用者實機多視窗（小工具 54、LINE 85、終端機 136、Spotify 122）：同一盆地、雪位 85、溢向 LINE；**只從終端機那段**用正常落雪餵雪，Spotify 那段也被填到同一雪面。
3. 100 pt 平底兩直牆：整段都是盆地。
4. 盆內高台：低於雪位 → 同一盆地；高於雪位 → 分成兩盆，各自溢出口正確。
5. 有通往地面的空隙：不是容器。
6. 短板沒有 SnowDrift：溢出變鬆雪，逐步核對「積雪＋鬆雪＋待釋放」總量守恆。
7. 接縫與圓角：盆地內與盆地↔牆頂之間，相鄰樣點雪面高度差 ≤ 4 pt。
8. 寬於 160 pt 的盆地：不是容器。
9. 既有測試全數通過（BridgedEnd 以雪面離平頂高度衡量）。
